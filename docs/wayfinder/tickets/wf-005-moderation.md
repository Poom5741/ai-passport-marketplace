## Question

**What happens when someone posts spam, a phishing link, or inappropriate content to AI Passport Marketplace?**

This platform represents Thailand's government AI education brand. There is no content moderation plan, no terms of service, no report mechanism, and no takedown path. The moment a phishing link appears in a project and gets reported to the government, there's a problem.

Options:
- **No moderation for MVP (accept the risk)** — low traffic, unlikely to be targeted. If something bad happens, deal with it manually.
- **Link scanning via Cloudflare** — Cloudflare has a "Content Scanning" add-on that can scan uploaded files and block malicious content. Costs money, adds complexity.
- **Manual report path** — a simple "Report this project" link that sends an email to the admin. No automation, just a contact form.
- **Terms of Service + user flagging** — write a ToS, require users to agree, add a flag button on projects. Moderation is still manual.

**What's the minimum viable moderation posture for a government-adjacent learner showcase?**

**Resolution: ToS + user flagging.** Simple ToS at signup. "Report" flag on projects. Admin reviews manually. No paid scanning add-ons.
